# Homepage Hero Assets

Both homepage entrance images were created as original, text-free raster artwork with the built-in image-generation capability for OpenSpec change `redesign-homepage`. The generated PNG sources remain outside the repository; the application uses the compressed WebP derivatives below.

| Asset | Intrinsic size | File size | Desktop focal position | Mobile focal position |
| --- | ---: | ---: | --- | --- |
| `earth-explorer-archive.webp` | 1536×1024 | 160,184 bytes | `68% 48%` | `66% 42%` |
| `game-chronicle-archive.webp` | 1717×916 | 137,030 bytes | `68% 46%` | `69% 44%` |

Generation constraints shared by both assets:

- world-game-archive still life with restrained retro magazine-collage texture;
- coal black, paper yellow, dark oxblood, oxidized brass, and muted olive palette;
- lower-left copy-safe area for live DOM labels;
- no text, letters, numbers, dates, logos, trademarks, watermarks, UI copy, or readable markings;
- no sci-fi blue, neon, holograms, or glassmorphism.

Earth Explorer uses a monumental unlabeled globe as the stronger focal subject. Game Chronicle uses unmarked collection objects, archival drawers, brass rails, and an armillary-like object to suggest time and preservation with lower visual dominance.
